# JAL Flight Board

ODPTのJAL・ANA運航情報と、ローカルCSVのSkymark時刻表を利用し、「現在飛行中」と「これから出発」を表示するWebサイトです。

- 飛行中便は実際の出発時刻と、本来の出発・到着予定時刻を併記
- 国内線・国際線の分類と絞り込み
- 本日・明日ごとのグループ表示。空港別・機種別の並べ替えでは同じ項目内を出発時刻順に表示
- 出発空港、到着空港、出発時刻、到着時刻、機種で並べ替え
- 便名、空港、機種で検索
- 検索対象を「すべて・出発空港のみ・到着空港のみ」から選択
- JAL・ANA・Skymarkをタブで切り替え
- Skymarkの飛行中便はCSV時刻表から推定し、画面上で明示
- 日付を跨ぐ到着時刻を `05:00 (+1)` の形式で表示

ODPTのJAL時刻表に含まれない国際線などは、到着予定時刻を「時刻表未提供」と表示します。

## 起動

Node.js 18以降で実行してください。外部パッケージのインストールは不要です。

```bash
npm start
```

ブラウザで <http://localhost:3000> を開きます。

アクセストークンは `.env` の `ODPT_ACCESS_TOKEN` に設定します。`.env` はGit管理対象外です。
